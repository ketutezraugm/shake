### Judge synthesis
- Shared: agents with wallets are plausible and interesting, but all flag security, liability, identity, reliability. Mert/Kain: security-first. Haseeb: anti-hype, wants measured reliability. Illia: privacy + user ownership. Garg: legal/economic primitives.
- Likely allergic: agent tokens/memecoin wrappers, "chatbot + swap" demos, unaudited autonomy with real funds, UX that needs a crypto-native.

### (1) Patterns among winners
- Real payment rail in the demo (x402, CDP wallet, Intents), not mock.
- Narrow, concrete job with a number (yield, domain, measurable benchmark) over general "agent platform."
- Infrastructure/novel primitive can beat apps (Unruggable, CrowdBrain), i.e. a physical or non-obvious angle.
- Privacy/TEE gets explicit sponsor recognition in NEAR events.
- Working live demo and public repo; Useful Agents rewarded measured performance.
- Winning pool skews to finance verticals plus one wildcard.

### (2) Ideas judges are likely tired of
- Generic "AI agent that swaps/trades for you" via chat (many Intents/Zcash agent wrappers).
- Yield-optimiser agents (Mamoriko type).
- Agent launchpads/tokens, "AI memecoin" tie-ins (Haseeb called it a craze).
- Agent marketplaces / "agent-to-agent economy" with no real counterparties (AgentOS-style, Infinite Bazaar-style).
- Wallet-for-agent wrappers over CDP/AgentKit.
- Agent that enters hackathons itself.
- Thin NEAR Intents swap UI or ZEC bridge frontends.
These are my inference from recurrence in winners and entry titles, not judge statements.
