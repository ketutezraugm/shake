# Design references

- `shake-marketplace-screens.html`: Abel's Claude Design export of every marketplace screen (MK-30, asking price per MK-32): phone frames at 390 px and desktop frames at 1280 px, direction G tokens. Open it in a browser; buttons jump between screens. Grey boxes are photo placeholders. It loads Manrope from Google Fonts, so it needs a connection; the app itself self-hosts the font. Frontend builds from these frames and invents no visual decisions.
